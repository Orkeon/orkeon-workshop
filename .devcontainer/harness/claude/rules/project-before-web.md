# The project before the web

Loaded in every session (no `paths:`): it holds wherever a web tool can answer — `WebSearch`, `WebFetch`, or a
crew's `web_search`, `http_api`, `web_scrape`. Ported from Orkeon Code (59772f3): a session had sent the user to
an unknown repository and a wrong port while the project documented a local image and its command.

- **The project's sources come first.** A port, a command, an image, a version or a setting that the project's
  documentation, its example settings (`appsettings*.json`, `.env.example`, `docker-compose*.yml`, `repo.yaml`,
  a README) or its code give wins over one found on the web. Read them before searching; a web result that
  disagrees with them is reported as a disagreement, never applied over them.
- **A value read nowhere is not a fact.** A value neither the project nor a source you read gives is said as
  unknown, or as an assumption naming what would settle it — never written into a file, a command or an answer
  as if it had been read.
