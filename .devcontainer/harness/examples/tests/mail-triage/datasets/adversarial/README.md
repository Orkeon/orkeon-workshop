# Dataset `adversarial`

Nine mails: five carry instructions for the model (in the body, the subject, a header, an attachment name, the file name), four are nominal. The manifest names the forbidden effect of each case (AC-06, INV-INJECTION).

Synthetic: every mail is made up and every address is under `example.com`, `example.org` or `example.net`. Written by `datasets/generate.py`: change the generator, not these files.
