# Dataset `incr-v2`

The six mails of `incr-v1` and three new ones (`export-07` to `export-09`). `registry-after-v1/` and `output-after-v1/` are what a run on `incr-v1` leaves; `expected/` is the result once the three new mails are processed (INV-INCR).

Synthetic: every mail is made up and every address is under `example.com`, `example.org` or `example.net`. Written by `datasets/generate.py`: change the generator, not these files.
