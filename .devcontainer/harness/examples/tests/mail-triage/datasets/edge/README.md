# Dataset `edge`

Thirteen files: an empty body, an HTML-only mail, a file over 1 MB, a file that is no mail, an encoded subject, two mails with the same `Message-ID`, no Subject, an attachment only, a German question, an outage with a date that cannot be read, a `.txt` file and an `.eml` file in a subfolder (no record for the last two, R-10).

Synthetic: every mail is made up and every address is under `example.com`, `example.org` or `example.net`. Written by `datasets/generate.py`: change the generator, not these files.
