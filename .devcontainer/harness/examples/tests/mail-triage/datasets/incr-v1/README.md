# Dataset `incr-v1`

A first export of six mails. `registry-recorded/` holds the registry a first run leaves; bound to `/registry` with an empty `/output`, it is the case of the outputs deleted by hand (AC-11): the registry alone decides, nothing is processed again.

Synthetic: every mail is made up and every address is under `example.com`, `example.org` or `example.net`. Written by `datasets/generate.py`: change the generator, not these files.
