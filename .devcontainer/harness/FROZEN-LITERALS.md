# Frozen literals

Strings that one component emits and another parses by exact match. Reword one and you reword its
parser, its template and its eval **in the same change** — a pair left out of step fails silently:
the guard stops firing, the gate stops opening, and nothing reports it.

How to read the tables: *Emitted by* writes the string, *Parsed by* matches it, *Eval* is the case
file that fails when either side moves (`evals/cases/<name>.json` here; `bench/tests/…` for the side
that lives in `orkeon-bench`). "lot n" marks a component that does not exist yet: the literal is
frozen now so that it is born matching.

Paths are relative to the harness (`claude/…` is `.claude/…` in a workshop); `bench/` is
`.devcontainer/bench/` in the image sources.
